## About

Fullstack software developer based in **Depok, Indonesia**, and a graduate of the **Hacktiv8** bootcamp. I design and build backend services and the interfaces that sit on top of them, with a focus on clean API design and reliable delivery.

- **APIs:** REST and GraphQL services with Node.js, Express.js, MongoDB, and PostgreSQL
- **AI:** LLM-powered features with Groq and LangChain (recommendations, chatbots, quiz generation)
- **Real-time & payments:** WebSockets with Socket.IO, subscription flows with Midtrans
- **Teamwork:** Led a 4-person team as project coordinator through a 7-day sprint
- **Open to:** Backend and Fullstack Developer roles
